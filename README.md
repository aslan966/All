# Культовые сериалы

Неофициальный фан-сайт в одном HTML-файле: герои, сезоны, факты и викторины по десяти сериалам.

**Сериалы:** Менталист, Шерлок (BBC), Во все тяжкие, Игра престолов, Друзья, Теория большого взрыва, Офис, Очень странные дела, Доктор Хаус, Острые козырьки.

## Что внутри
- переворачивающиеся карточки героев со шкалами, поиск, сортировка, случайный герой и сравнение двух героев;
- описание, сезоны (с пересказами и спойлерами), факты и викторина для каждого сериала;
- у каждого сериала своя интерактивная «изюминка» и камео другого сериала;
- светлая и тёмная тема, управление стрелками ← →.

## Запуск
Откройте `index.html` в браузере. Сборка не нужна, всё лежит в одном файле. Шрифты подгружаются из Google Fonts.

## Публикация на GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Дисклеймер
Проект неофициальный. Названия сериалов и связанные обозначения принадлежат их правообладателям. Шкалы героев отражают субъективную оценку автора.
